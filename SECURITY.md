# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private reporting instead:
**Security → Report a vulnerability** on this repository.

Include what you found, the module version, and the steps to reproduce it. You will get an answer as soon as possible.

## Supported versions

Only the latest release receives fixes.

## Scope

This module adds a second factor to the OXID eShop admin login. Reports about bypassing the second factor, weaknesses
in secret or recovery code handling, and the attempt limit are in scope. Problems in the OXID eShop itself belong to
OXID eSales.
